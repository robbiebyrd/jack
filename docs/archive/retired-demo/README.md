# Retired mouth demo (archived 2026-10-08)

These modules played fixed and random mouth movements before the talk loop and show control
existed (`SPEC.md` "Smoke test behavior", up to tag `pre-show-control-demo`). They are not imported
by anything, not tested, and their voltages predate the 2026-10-02 recalibration (the mouth now
opens on positive volts; these open on −6 V). They are kept here only as a record; delete the
directory when it is no longer wanted. The complete working demo is at `git show pre-show-control-demo`.
