# ROC Voice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Jack hears voice streamed from a Mac over Roc Toolkit (roc-vad → `roc-recv` on the Pi), mixed with Mumble, which stays as a fallback.

**Architecture:** A new adapter, `jack/adapters/audio/roc_voice.py`, runs `roc-recv` as a child process writing raw stereo 16-bit samples to stdout; a reader thread keeps the left channel and feeds a `FrameQueue`, and `take_frames()` hands the talk loop one 20 ms mono frame (skipping digital silence). It restarts `roc-recv` if it exits. `main.py` reads four `JACK_ROC_*` settings, starts the adapter, passes `[mumble_voice, roc_voice]` to the talk loop, closes it on exit, and no longer exits when Mumble's client thread dies.

**Tech Stack:** Python 3.13 (`subprocess`, `threading`, `array`), pytest. Run tests with `.venv/bin/python -m pytest -q -W error` from the repo root (`/Users/robbiebyrd/jack`).

**Spec:** `SPEC.md` → "Talking" → "ROC voice" and "Failure handling" (commit 1a244bc).

## Global Constraints

- Work directly on `main`; no branches or worktrees. Other sessions may share the checkout: stage only the files a task names (never `git add -A`; `commands-to-run.txt` is not ours). Do not push.
- TDD; test output pristine under `-W error` (no `ResourceWarning` from unclosed pipes or un-waited processes).
- Layering (SPEC "Package layout", enforced by `tests/test_layers.py`): `subprocess` and `threading` I/O stay in `jack/adapters/`; imports use full paths.
- Exact `roc-recv` command (SPEC): `roc-recv -s rtp+rs8m://0.0.0.0:<source> -r rs8m://0.0.0.0:<repair> -c rtcp://0.0.0.0:<control> -o file:- --output-format s16 --rate 48000 --target-latency=<ms>ms`.
- Output format (measured): raw stereo signed 16-bit native-endian at 48 kHz, both channels identical, real-time paced, digital silence while nobody sends.
- Settings (SPEC): `JACK_ROC_SOURCE_PORT` 10001, `JACK_ROC_REPAIR_PORT` 10002, `JACK_ROC_CONTROL_PORT` 10003 (1–65535); `JACK_ROC_TARGET_LATENCY_MS` 100 (positive number). Bad value → one-line `SystemExit` naming the variable.
- Failures (SPEC): `roc-recv` missing at startup → exit with `roc-recv not found: sudo apt install roc-toolkit-tools`; `roc-recv` exits while running → log `roc-recv exited (code N); restarting` (at most one line a minute), wait 2 s, start again; shutdown → SIGTERM, then kill after 1 s; Mumble client thread dies → log `Mumble stopped; ROC still works` once and keep running (watchdog keeps pinging).
- `deploy/install.sh` installs `roc-toolkit-tools`.

## Review Focus

- `roc-recv` sends continuous digital silence; if every silent frame reached the talk loop, every Mumble tick would go through `pcm.mix`'s per-sample Python loop instead of its one-source fast path: `take_frames()` must skip all-zero frames (test in Task 1).
- Output split at arbitrary byte boundaries (mid-sample, mid-stereo-pair, mid-frame) must still give exact mono frames (test in Task 1).
- `roc-recv` vanishing between restarts (package removed) must not kill the reader thread: it logs and keeps retrying (test in Task 1).
- A child that ignores SIGTERM must still be gone after `close()` (test in Task 1).
- Mumble's client thread dying must keep the watchdog pinging (else systemd kills a Jack that still works on ROC) and log only once, not every second (test in Task 2).

```python
"""VoiceSource for a Roc Toolkit stream: Jack runs roc-recv and hears whatever a sender (e.g. roc-vad on a Mac) plays.

roc-recv writes raw stereo signed 16-bit samples at 48 kHz to stdout in real time, both channels
identical, and digital silence while nobody sends. A reader thread keeps the left channel, cuts
it into talk-loop frames, and restarts roc-recv if it exits. See "ROC voice" in SPEC.md.
"""

import subprocess
import threading
import time
from array import array
from collections.abc import Callable, Sequence

from jack.show.audio.frame_queue import FrameQueue
from jack.show.audio.pcm import SAMPLE_RATE_HZ
from jack.support.rate_limited_log import RateLimitedLog

# One stereo sample pair: two signed 16-bit samples.
STEREO_SAMPLE_BYTES = 4
READ_BYTES = 65536
RESTART_LOG_INTERVAL_S = 60.0


def roc_recv_command(source_port: int, repair_port: int, control_port: int, target_latency_ms: float) -> list[str]:
    """roc-recv listening on every interface, writing raw stereo s16 at the talk loop's rate to stdout."""
    return [
        "roc-recv",
        "-s", f"rtp+rs8m://0.0.0.0:{source_port}",
        "-r", f"rs8m://0.0.0.0:{repair_port}",
        "-c", f"rtcp://0.0.0.0:{control_port}",
        "-o", "file:-",
        "--output-format", "s16",
        "--rate", str(SAMPLE_RATE_HZ),
        f"--target-latency={target_latency_ms:g}ms",
    ]


class RocVoice:
    def __init__(
        self,
        command: Sequence[str],
        max_backlog_frames: int,
        log: Callable[[str], None],
        restart_delay_s: float = 2.0,
        stop_grace_s: float = 1.0,
    ):
        self._command = list(command)
        self._queue = FrameQueue(max_backlog_frames)
        self._log = RateLimitedLog(log, RESTART_LOG_INTERVAL_S, time.monotonic)
        self._restart_delay_s = restart_delay_s
        self._stop_grace_s = stop_grace_s
        self._closed = threading.Event()
        self._lock = threading.Lock()
        self._process: subprocess.Popen | None = None
        self._thread: threading.Thread | None = None

    def start(self) -> None:
        """Start roc-recv and its reader thread. Raises FileNotFoundError when roc-recv isn't installed."""
        self._process = self._spawn()
        self._thread = threading.Thread(target=self._run, name="roc-voice", daemon=True)
        self._thread.start()

    def take_frames(self) -> list[bytes]:
        """The next frame while someone is sending; nothing for digital silence, so it mixes as no voice."""
        frame = self._queue.take()
        return [frame] if frame is not None and any(frame) else []

    def close(self) -> None:
        """Stop roc-recv (SIGTERM, then a kill after the grace period) and the reader thread."""
        self._closed.set()
        with self._lock:
            process = self._process
        if process is not None:
            _stop(process, self._stop_grace_s)
        if self._thread is not None:
            self._thread.join()

    def _spawn(self) -> subprocess.Popen:
        return subprocess.Popen(self._command, stdout=subprocess.PIPE)

    def _run(self) -> None:
        process = self._process
        while True:
            if process is not None:
                code = self._read_until_exit(process)
                if self._closed.is_set():
                    return
                self._log("exited", f"roc-recv exited (code {code}); restarting")
            if self._closed.wait(self._restart_delay_s):
                return
            try:
                process = self._spawn()
            except OSError as error:
                process = None
                self._log("spawn", f"roc-recv could not start ({error}); retrying")
                continue
            with self._lock:
                if self._closed.is_set():
                    # close() ran while this one was starting; nothing will read its pipe.
                    _stop(process, self._stop_grace_s)
                    process.stdout.close()
                    return
                self._process = process

    def _read_until_exit(self, process: subprocess.Popen) -> int:
        """Feed roc-recv's output to the queue until it ends; return its exit code."""
        pending = b""
        with process.stdout:
            while chunk := process.stdout.read1(READ_BYTES):
                data = pending + chunk
                whole = len(data) - len(data) % STEREO_SAMPLE_BYTES
                pending = data[whole:]
                left = array("h", data[:whole])[0::2].tobytes()
                self._queue.put(left)
        return process.wait()


def _stop(process: subprocess.Popen, grace_s: float) -> None:
    if process.poll() is not None:
        return
    process.terminate()
    try:
        process.wait(grace_s)
    except subprocess.TimeoutExpired:
        process.kill()
        process.wait()
```

````markdown
### Talking over ROC (from a Mac)

1. Install the Roc Virtual Audio Device on the Mac (the installer may report errors on `/usr/` and
   `/Library/` while still installing both files), then reboot:
   `sudo /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/roc-streaming/roc-vad/HEAD/install.sh)"`
2. Check it: `roc-vad info` says `driver is loaded`.
3. Create a sender and point it at the Pi (use the id `roc-vad device list` shows):
   ```bash
   roc-vad device add sender --name "Jack"
   roc-vad device connect 1 \
     --source rtp+rs8m://10.10.0.54:10001 \
     --repair rs8m://10.10.0.54:10002 \
     --control rtcp://10.10.0.54:10003
   ```
4. Choose "Jack" as the Mac's sound output (System Settings → Sound → Output). Anything the Mac
   plays comes out of Jack, about 0.1 s later; you won't hear it on the Mac.

If the sound breaks up, raise `JACK_ROC_TARGET_LATENCY_MS` (below); on the home Wi-Fi 90 ms held
and 60 ms broke up.
````

- Add four rows to the "Settings in `/etc/jack/jack.env`" table:

```markdown
| `JACK_ROC_SOURCE_PORT` | `10001` | ROC audio (RTP) UDP port |
| `JACK_ROC_REPAIR_PORT` | `10002` | ROC repair (FEC) UDP port |
| `JACK_ROC_CONTROL_PORT` | `10003` | ROC control (RTCP) UDP port |
| `JACK_ROC_TARGET_LATENCY_MS` | `100` | ROC's latency target; raise it if the sound breaks up |
```
